# Identity Server X

**Identity Server X** is a cutting-edge identity and access management solution built as an upgrade to **Identity Server 4**. It provides secure, flexible authentication and authorization for modern applications, supporting **OpenID Connect** and **OAuth 2.1**. Whether you're building cloud-native apps or large-scale enterprise systems, Identity Server X delivers enhanced performance, scalability, and security.

## Key Features:
- **Advanced Security**: Full support for OpenID Connect and OAuth 2.1.
- **Cloud-Ready**: Optimized for performance in cloud environments.
- **Customizable**: Easily adaptable authentication and authorization flows.
- **Seamless Upgrade**: Built on Identity Server 4, making upgrades easy for existing users.

## How to build

* [Install](https://www.microsoft.com/net/download/core#/current) the latest .NET 6.0 SDK
* Install Git
* Clone this repo
* Run `build.ps1` or `build.sh` in the root of the cloned repo
